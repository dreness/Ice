# Privacy Policy

## Overview

Ice is committed to protecting your privacy. This document outlines what data is and is not collected by Ice.

## Data Collection

**Ice does not collect, store, or transmit any personal information or usage data.**

Specifically:
- ❌ No analytics or telemetry
- ❌ No crash reporting to external services
- ❌ No tracking of user behavior
- ❌ No collection of personal information
- ❌ No system profiling data sent to servers
- ❌ No advertising or tracking identifiers

## Network Activity

Ice only makes network connections for the following purposes:

### Automatic Updates (Optional)

Ice uses the Sparkle framework to check for updates. This feature can be disabled in the app's settings.

When checking for updates:
- **URL contacted**: `https://jordanbaird.github.io/ice-releases/appcast.xml`
- **Data sent**: None. System profiling is explicitly disabled.
- **Data received**: Information about available updates (version numbers, release notes, download URLs)
- **User control**: You can disable automatic update checks in Settings → About

### External Links (User-Initiated Only)

The app includes links to external websites that are only opened when you explicitly click them:
- GitHub repository: For viewing source code and reporting issues
- Donation page: For supporting the project

These links open in your default web browser and are subject to those websites' privacy policies.

## Local Data Storage

Ice stores the following data locally on your Mac:
- **Application preferences**: Your settings and configuration (stored in standard macOS preference files)
- **Menu bar layout**: Information about how you've arranged your menu bar items
- **Image cache**: Cached images of menu bar items for faster rendering

All data is stored locally and never transmitted over the network.

## Permissions

Ice requires certain macOS permissions to function:

- **Accessibility**: Required to detect and arrange menu bar items
- **Screen Recording**: Optional, used to capture images of menu bar items for display purposes

These permissions are used solely for the app's core functionality and do not involve any data transmission.

## Third-Party Services

Ice does not integrate with any third-party analytics, advertising, or tracking services.

## Changes to This Policy

Any changes to this privacy policy will be documented in this file and versioned through the project's git repository.

## Contact

If you have questions about this privacy policy, please open an issue on the [GitHub repository](https://github.com/jordanbaird/Ice/issues).
